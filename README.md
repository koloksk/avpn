# AVPN - Automatic VPN and Proxy Detection for Minecraft Servers

**AVPN** is a comprehensive and advanced plugin for Minecraft servers that automatically detects players using VPN and proxy services, blocking their access to the server. With AVPN, you can effectively secure your server against unwanted users, bots, and attempts to bypass security measures.

## Key Features:

- **Automatic Detection**: AVPN thoroughly analyzes players' IP addresses, identifying connections from VPN and proxy networks, allowing for the immediate blocking of potentially dangerous users.
- **Log Filtering**: In the event of a bot attack, the plugin automatically filters logs to prevent console clutter and facilitate server management during challenging times.
- **Wide Compatibility**: The plugin is compatible with Minecraft engines from Bukkit version 1.8 to 1.21 and also supports BungeeCord and Velocity, ensuring compatibility with various server configurations.
- **High Performance**: The optimized code ensures minimal impact on server performance, allowing for smooth operation even with a large number of players and heavy network traffic.
- **Integrations**: AVPN works seamlessly with popular login plugins, further enhancing security levels.
- **Discord Notifications**: The plugin offers Discord integration, enabling notifications to be sent to a Discord server about detected VPN/proxy connections and other important events.

## Installation

1. Download the latest version of the `.jar` file from the [releases](https://github.com/koloksk/avpn/releases) section.
2. Move the file to the `plugins` folder on your Minecraft server.
3. Start the server to install the plugin and generate the necessary configuration files.
4. Customize the settings in the `config.yml` file to suit your needs.

## Plug and Play

AVPN is ready to use immediately after installation, while also offering a wide range of configuration options. All settings can be easily adjusted in the `config.yml` file, allowing full control over the plugin's operation.
