# AVPN - Automatyczne Wykrywanie Proxy i VPN dla Serwerów Minecraft

**AVPN** to wszechstronny i zaawansowany plugin dla serwerów Minecraft, który automatycznie wykrywa graczy korzystających z usług VPN i proxy, blokując ich dostęp do serwera. Dzięki AVPN, możesz skutecznie zabezpieczyć swój serwer przed niechcianymi użytkownikami, botami oraz próbami omijania zabezpieczeń.

## Kluczowe funkcje:

- **Automatyczne wykrywanie**: AVPN dokładnie analizuje adresy IP graczy, identyfikując połączenia z sieci VPN i proxy, co pozwala na natychmiastowe zablokowanie potencjalnie niebezpiecznych użytkowników.
- **Filtracja logów**: W przypadku ataku botów, plugin automatycznie filtruje logi, aby zapobiec zaśmieceniu konsoli i ułatwić zarządzanie serwerem w trudnych momentach.
- **Szeroka zgodność**: Plugin jest kompatybilny z silnikami Minecraft od wersji Bukkit 1.8 do 1.21, a także obsługuje BungeeCord oraz Velocity, zapewniając wsparcie dla różnych konfiguracji serwerów.
- **Wysoka wydajność**: Zoptymalizowany kod zapewnia minimalny wpływ na wydajność serwera, co pozwala na płynne działanie nawet przy dużej liczbie graczy i intensywnym ruchu sieciowym.
- **Integracje**: AVPN współpracuje z popularnymi pluginami do logowania, co dodatkowo zwiększa poziom bezpieczeństwa.
- **Powiadomienia Discord**: Plugin oferuje integrację z Discordem, umożliwiając wysyłanie powiadomień na serwer Discord o wykrytych połączeniach VPN/proxy oraz innych ważnych zdarzeniach.

## Instalacja

1. Pobierz najnowszą wersję pliku `.jar` z sekcji [releases](https://github.com/koloksk/avpn/releases).
2. Przenieś plik do folderu `plugins` na swoim serwerze Minecraft.
3. Uruchom serwer, aby plugin mógł się zainstalować i wygenerować niezbędne pliki konfiguracyjne.
4. Dostosuj ustawienia w pliku `config.yml` do własnych potrzeb.
